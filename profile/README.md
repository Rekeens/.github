# Rekeens

We are a small engineering studio building web and mobile products with Laravel and Flutter. Founded in 2015, run by Igor and Constanta.

Most of our work comes from two places:
- **Digital agencies** that need a technical partner for their client projects.
- **Product teams** that need extra senior hands without a six-month hiring process.

## What we do

- **Laravel backends** — APIs, integrations, and rescuing projects that got stuck.
- **Flutter apps** — Mobile apps for iOS and Android.
- **Architecture & refactoring** — Untangling messy codebases so they are easy to maintain.

## Products

- [Boosik](https://play.google.com/store/apps/details?id=com.rekeens.boosik) — Platform for intercity transportation in Moldova (Android).
- [RadioForce](https://github.com/igorsmoleac/radioforce-downloads) — Free, ad-free radio streaming app for Android, Windows, Linux and macOS.

## Open source

Tools we build and use ourselves:

- [design-laravel-kit](https://github.com/igorsmoleac/design-laravel-kit) — Blade components for Italian Public Administration sites (Laravel, Bootstrap Italia).
- [rekeens_flutter_cli](https://github.com/igorsmoleac/rekeens_flutter_cli) — CLI for scaffolding Flutter projects with feature-first clean architecture.
